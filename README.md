# Authentication System

A simple authentication system built with Next.js, PostgreSQL, Prisma, Zod, React Hook Form, and bcryptjs.

The project includes user registration and login with server-side validation, password hashing, database integration, and a simple responsive UI built with shadcn/ui.

## Live Link

[https://intern-evaluation-2zu3.vercel.app/](https://intern-evaluation-2zu3.vercel.app/)

## Features

- User registration
- User login
- PostgreSQL database
- Password hashing with bcryptjs
- Server-side request validation with Zod
- Client-side form validation with Zod
- Field-specific validation errors
- Duplicate email handling
- Invalid login handling
- Login success modal displaying the user's name
- Registration success feedback
- Responsive authentication UI
- Shared header and footer
- Navigation between Home, Login, and Register pages
